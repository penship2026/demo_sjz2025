# 人民干细胞学院网站说明文档

## 项目概述

人民干细胞学院网站是一个基于 HTML、CSS 和 JavaScript 构建的静态网站，致力于科学普及干细胞知识，促进学术交流，提升公众认知。

## 技术栈

- **HTML5**: 页面结构
- **CSS3**: 样式设计
- **JavaScript**: 交互功能
- **Tailwind CSS**: 实用优先的 CSS 框架（通过 CDN 引入）
- **Font Awesome**: 图标库（通过 CDN 引入）

## 页面说明

### 1. 首页 (index.html)
- **功能**: 网站主页面，展示轮播图和核心信息
- **特色功能**:
  - 自动轮播图（3张图片循环播放）
  - 轮播图指示器点击切换
  - 平滑滚动提示
  - 响应式设计

### 2. 学院介绍 (about.html)
- **功能**: 介绍学院背景、发起人、学术委员会职能和联系方式
- **内容模块**:
  - 发起人介绍
  - 学术委员会职能
  - 联系方式

### 3. 干细胞科普 (science.html)
- **功能**: 科普干细胞相关知识
- **内容模块**:
  - 干细胞是什么
  - 干细胞的作用
  - 干细胞研究进展

### 4. 专家讲坛 (experts.html)
- **功能**: 展示专家信息和讲座内容

### 5. 行业观察 (industry.html)
- **功能**: 行业动态和观察分析

### 6. 细胞风险评估 (assessment.html)
- **功能**: 细胞风险评估服务介绍

### 7. 城市讲堂 (city-lecture.html)
- **功能**: 城市讲堂活动信息

### 8. 学院动态 (news.html)
- **功能**: 学院最新动态和新闻

## 核心功能

### 1. 动态头部和页脚
- 通过 JavaScript 动态插入头部和页脚组件
- 支持当前页面导航高亮显示
- 响应式移动端菜单

### 2. 轮播图功能
- 自动播放（5秒间隔）
- 指示器点击切换
- 鼠标悬停暂停
- 响应式高度调整

### 3. 导航高亮
- 当前页面导航项显示蓝色字体和下划线
- 平滑的过渡动画效果
- 支持桌面端和移动端

### 4. 回到顶部
- 滚动超过300px时显示按钮
- 点击平滑滚动到顶部

### 5. 响应式设计
- 适配桌面端、平板和移动端
- 移动端汉堡菜单
- 灵活的布局调整

## 使用说明

### 本地开发
1. 进入项目目录:
   ```bash
   cd /Users/liyan/lark/git/gitee-lark/larker2017/sjz-wentian/source
   ```

2. 启动本地服务器:
   ```bash
   python3 -m http.server 8000
   ```

3. 浏览器访问:
   ```
   http://localhost:8000
   ```

### 直接打开
- 可以直接在浏览器中打开 `index.html` 文件查看网站
- 建议使用本地服务器以获得最佳体验

## 浏览器兼容性

- Chrome 80+
- Firefox 75+
- Safari 13+
- Edge 80+

## 注意事项

1. **图片资源**: 所有图片存储在 `assets` 文件夹中，确保图片路径正确
2. **跨域问题**: 直接打开 HTML 文件可能会遇到跨域问题，建议使用本地服务器
3. **CDN 依赖**: 网站依赖 Tailwind CSS 和 Font Awesome 的 CDN，需要网络连接

## 维护说明

### 添加新页面
1. 在 `pages` 文件夹中创建新的 HTML 文件
2. 复制现有页面结构，修改内容
3. 在 `main.js` 中添加导航链接

### 修改样式
1. 全局样式修改: 编辑 `css/style.css`
2. 页面特定样式: 在页面 HTML 中添加 `<style>` 标签

### 更新图片
1. 将新图片放入 `assets` 文件夹
2. 更新 HTML 中的图片路径
